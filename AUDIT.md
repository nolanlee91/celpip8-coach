# CELPIP 8 Coach — Audit Report (offline-first content refactor)

> Phase 3 (Learn Mode, curriculum, coaching) is audited in [AUDIT(3).md](AUDIT(3).md).

This report describes the current state of the repository after the **content-first / AI-optional refactor**, with exact counts and an honest list of what was and was not verified. It is written so an independent reviewer (e.g. Codex) can audit the code and the content library against the requirements.

- Repository: https://github.com/nolanlee91/celpip8-coach
- Stack: React 19 + Vite 8, Express 5 + `tsx`, TypeScript, Google Gemini via `@google/genai`
- Learner: Vietnamese adult in BC. Official CELPIP-General (Apr 2026): L6 / R5 / W7 / S6. Target ≥ 8 in **each** skill.
- All counts below were produced by scripts or command output on 2026-10-26. None are estimates.

## 1. What changed and why

**Before:** every exercise, writing/speaking prompt and mock exam was generated by AI on demand. A mock exam needed 20 AI calls before it could start, and nothing worked without an API key.

**After:** learning content is prebuilt and stored, the learning engine runs locally, and AI is optional.

| Layer | Contents | Location | Needs AI |
|---|---|---|---|
| **A. Static content** | Reading/Listening sets, Writing/Speaking prompts with Level 8 model answers, vocabulary, mock-exam packages | `content/` (git) + `$DATA_DIR/library/` (admin-imported) | No |
| **B. Learning engine** | Selection, local scoring, explanations, mistakes, SM-2, adaptive difficulty, planner, analytics, vocabulary review, mock exams | `server/selection.ts`, `server/analytics.ts`, `server/index.ts` | No |
| **C. AI assistance** | Writing/Speaking evaluation **on explicit request**, Tutor, admin generation/review/TTS | `server/ai.ts`, `server/prompts.ts`, `server/pipeline.ts` | Gemini |
| **D. Audio assets** | Pre-generated listening MP3s + manifest | `audio-assets/` (committed, 30 files, ~21 MB) + `$DATA_DIR/audio-assets/` (future server-side generation) | Edge TTS (default, no key) or Gemini TTS; generated once |

**Storage split** (`server/db.ts`):

| File | Contents |
|---|---|
| `progress.json` | Learner progress |
| `ai.json` | Evaluations, pending submissions, AI usage log, evaluation cache |

**Migration:** on first start, the legacy `db.json` is split into these two files. A backup is kept as `db.json.migrated-<timestamp>`. Legacy AI-generated items stay readable for history (`getContent` falls back to them) but are never selected for practice.

### How the content was produced and reviewed

1. **Authoring:** original content was written by Claude agents following `content/CONTENT_GUIDE.md`, with realistic BC/Canadian contexts and fictional organisations. Items were saved as `draft` and had to pass the validator.
2. **Independent review:** a separate Claude agent that did not write the items reviewed every item:
   - **Reading/Listening:** solved every question before looking at the key, tested every blank option, re-did every R2 calculation, checked trap tags, Vietnamese explanations and real-world facts.
   - **Writing/Speaking:** checked format, model answers and register.
   - **SVG scenes:** rendered each one to PNG and checked the model answer against what is actually drawn.
3. **Result:** **96/96 items approved** (`review.reviewedBy: "independent AI review (Claude)"`), 0 rejected. Each file's `review.notes` records what was checked or changed.

**Issues the reviewers caught and fixed** (examples, not exhaustive):

*Answer correctness*
- **Answer keys:** none of the 377 reading/listening questions had a wrong key.
- **Ambiguity:** 2 questions had a second defensible answer.
  - r2-drill-01 Q4: replaced "the whole year".
  - r3-drill-01 Q5: the statement was rewritten.
- **Self-contradiction:** r2-drill-02's email contradicted its own key.
- **Answers not supported by the article:**
  - r4-mock-01 blank 10 and r4-drill-01 blank 5 rested only on the comment's logic; article sentences were added.
  - Main-idea evidence was thin in 3 sets; better evidence was added.

*Factual and logic errors*
- l3-full-01: the benefits start date did not follow from the hiring date.
- r1-full-03: asked the reader to book off a statutory holiday (BC Day).
- r1-mock-01: claimed a fee for volunteer criminal record checks (they are free).
- l5-mock-01: wrong strata vote threshold for EV chargers.
- l2-full-01: overstated rule on transferring controlled prescriptions.

*Writing and speaking quality*
- Speaking model answers described things not drawn in the scene ("tying his shoe", "armrest with a cup holder").
- A drawn book was too small to recognise; it was enlarged.
- S5 prices were unrealistically low.
- A writing model answer had a timeline contradiction.
- British "Yours faithfully" was changed to "Sincerely".

*Vocabulary* — 137 of 400 entries changed:
- Misleading synonyms.
- Entries mixing two senses.
- Unverifiable or outdated specific figures replaced with generic wording.

**Caveat.** Both authoring and review were done by AI (Claude), and **no human has reviewed the content yet**. The validator proves structure, not exam quality. Treat this as "carefully AI-reviewed", not "expert-certified".

## 5. Audio

| Item | Value |
|---|---|
| **Listening audio files actually generated** | **30 MP3 files** (one per chunk) |
| **Listening sets ready** | **24/24** |
| Total duration | ~59 min |
| Size | ~21 MB |
| Provider | Edge TTS (`msedge-tts`, format `audio-24khz-48kbitrate-mono-mp3`) |

**Voices:**

| Script role | Voice |
|---|---|
| `female_a` | en-CA-ClaraNeural |
| `male_a` | en-CA-LiamNeural |
| `narrator` | en-CA-LiamNeural (only used alone, in L4 news) |
| `female_b` | en-US-JennyNeural |
| `male_b` | en-US-GuyNeural |

Edge offers only two Canadian neural voices. Override the mapping with `EDGE_TTS_VOICES`.

**How it is generated:**
- One request per dialogue segment, joined with silent MPEG frames (0.25 s for a single speaker, 0.4 s between speakers).
- The stream is constant bitrate, so the manifest stores **exact segment offsets**; transcript replay is exact, not estimated.
- Ran with 6 parallel workers: the last 14 chunks took 1.1 minutes, with 0 failures.
- File names include a hash of the script and voices, so editing a script automatically marks that chunk as needing regeneration.

**Where it is stored:**
- **Committed** in `audio-assets/`, so a fresh Railway deploy plays immediately with no admin action.
- Audio generated later on the server goes to `$DATA_DIR/audio-assets/`.
- The server reads both stores (`audioFilePath`).

**Verification:**
1. In a **fresh deploy simulation** (empty `DATA_DIR`, audio served only from the bundled folder), headless Microsoft Edge loaded and **decoded all 30/30 files**. Decoded durations match the manifest within **0.05 s**, which confirms the hand-built silent frames are valid MP3.
2. Listening selection returns sets with `audio.ready=true` and no browser-voice fallback.
3. Both mock packages report `available=true`.

**Caveats:**
- **Edge TTS is an unofficial Microsoft service.** Availability or terms may change. Already-generated files are unaffected; only generating new audio could break, in which case use `AUDIO_PROVIDER=gemini`.
- **The Gemini TTS path is still untested** against the live API.
- **Nobody has listened to the audio.** No human has checked pronunciation or naturalness.
- **Pending-audio rule still applies:** sets without audio are labelled pending and excluded, never silently turned into text practice. Browser TTS remains an explicit, labelled opt-in.

## 6. Works without AI vs needs Gemini

**Works without any API key** (verified by `npm run test:smoke`):

- **Reading:** recommended or browsed selection, instant load (~30 ms), timer, highlighting, local scoring, explanations with evidence, weakness report, drills by category.
- **Listening:** all 24 sets with real pre-generated audio (bundled). Single-play exam restrictions, transcript with exact sentence replay.
- **Vocabulary:**
  - Library of 400 entries.
  - Adding words: from the library, or saved manually without a meaning.
  - Enrichment from the library.
  - 4 review modes + SM-2.
- **Mistakes:** mistake notebook + SM-2 review.
- **Planning:** adaptive difficulty, daily plan (30/60/90/120 min), weekly check-in and weight adjustment, dashboard, analytics.
- **Writing/Speaking:** prompt loads instantly. The response or recording is saved and the Level 8 model answer, structure, expressions and common mistakes are shown immediately.
- **Mock exams:** start instantly from a package (measured 4 ms), with exam restrictions. Listening/Reading are scored locally. Writing/Speaking are stored and evaluated later.
- **Data:** export/import, Railway health check, password protection.

**Requires Gemini:**

| Feature | Trigger |
|---|---|
| Writing evaluation | "Nhận xét bằng AI" button only |
| Speaking transcript evaluation | "Nhận xét bằng AI" button only |
| AI Tutor | — |
| Vocabulary AI lookup | Checkbox / "…hoặc bằng AI" |
| Admin: content generation + independent AI review | Admin action |
| Admin: listening audio generation with `AUDIO_PROVIDER=gemini` only | Admin action (the default Edge provider needs no key) |

**Cost controls:**
- **Models:** configurable through `GEMINI_MODEL` (default `gemini-2.5-flash`, which has a free tier) and `GEMINI_TTS_MODEL`.
- **Usage log:** every call is logged with tokens from `usageMetadata` (Admin → *Sử dụng AI*, by kind and by day).
- **Rate limits:** after a 429, further calls back off for 60 s.
- **Evaluation cache:** an identical response reuses the earlier evaluation (toggle in Settings).
- **Manual retry:** failed or pending submissions keep a retry button.
- **Visibility:** AI availability is shown in Settings and Admin.

## 8. Remaining limitations / known issues

1. **Audio quality is unreviewed by a human.** The audio comes from Edge TTS, an unofficial service that may change. Two of the five voices are US rather than Canadian. The Gemini TTS alternative is untested.
2. **Content volume is small** compared with the targets. Listening has only 1 `full` set per part for normal practice (plus 1 drill); the 12 `mock` sets are reserved for the two packages. The selector repeats least-recently-used sets once new ones run out and says so.
3. **Content review was AI-only.** No human expert has checked the answer keys or explanations.
4. **Sentence-level replay:** segment offsets are exact for the Edge audio. Sentences within a segment are estimated from text length. Gemini multi-speaker chunks would use estimated offsets.
5. **Speaking** feedback is transcript-only; pronunciation is not assessed (disclosed in the UI). STT needs Chrome/Edge.
6. **Reading/Listening estimates** are heuristics, not official conversion tables.
7. **AI generation pipeline:** never run live. JSON-schema features (`anyOf` null, `additionalProperties:false`, nested `rows: string[][]`) might be rejected by some Gemini models.
8. **Security:** Basic auth has no rate limiting. Answer keys are stripped only in `mode=exam` responses (fine for a single-user app).
9. **Single-process storage:** JSON files with serialized atomic writes; not for multi-instance deployment.
10. **Prior audit issues:** the W2 word-count prefix bug is fixed (the chosen option is stored separately), and the weekly Speaking link now carries `mode=weekly`.
